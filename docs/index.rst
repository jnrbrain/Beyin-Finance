Beyin Finance API Documentation
================================

Read public market data, connect a server-side integration, and follow a
strategy from generation through backtesting and Marketplace publishing.

You can make your first market quote request before creating a Developer
API key.

* :doc:`quickstart` — Make a public request, then verify your credentials.
* :doc:`strategy-backtest` — Estimate credits, track progress, recover jobs,
  and select a result for publishing.
* :doc:`troubleshooting` — Handle errors, throttling, and uncertain outcomes.
* :doc:`endpoints` — Find request fields, response examples, and limits.
* :doc:`operations` — Look up an operation by method or request path.
* :doc:`education` — Browse the catalog and learn how student and instructor
  operations are authorized.
